# QuickPic Tracker

Live build status for QuickPic (quickpic.click) - what's shipped, in
progress, and planned across the booking platform and photographer
marketplace.

`data/tracker.json` is the single source of truth. Every status change is
a git commit here, so the commit history doubles as a build changelog.

Published via GitHub Pages once enabled: Settings -> Pages -> Deploy from
branch -> main -> / (root).
